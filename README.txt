FILES
- index.html: website content
- style.css: responsive styling
- script.js: mobile navigation, current year and reveal animations

PREVIEW
Keep all three files in the same folder. Open index.html in a browser or use VS Code Live Server. Internet is required for Google Fonts; fallback fonts are included.

BEFORE PUBLISHING
- Verify your personal details, education, CGPA, internship dates and skills.
- GitHub and LinkedIn URLs were carried over from your uploaded portfolio; verify they are yours.
- The AAPS URL is clearly labelled as the organization website, not a personal live project demo.
- Resume & JD Matcher has no fabricated URL. Add your real repository link once it exists.
- Add a real resume PDF and a download button only after placing the correct PDF in this folder.
- Do not publish confidential internship code or data.

GITHUB PAGES
1. Create a GitHub repository.
2. Upload index.html, style.css, script.js and README.txt to the repository root.
3. Go to Settings > Pages.
4. Select Deploy from a branch, choose main and /(root), then Save.
5. Open the published URL shown by GitHub Pages.

This static portfolio needs no backend or database.
